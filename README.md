# Premodern

Проекты по премодерну.

## TourneyDashes

Даши регистрации на турниры. Каждый турнир живёт по адресу
`https://solthecaptain.github.io/Premodern/TourneyDashes/<id>/`.

- `config.json` — список турниров: `id` (папка в адресе), `title`, `event` (после формата в шапке), `date`, `cap` (кап участников), `csv` (`"$СЕКРЕТ"` со ссылкой на CSV листа Main).
- `collect.py` — качает CSV, собирает страницу из `template.html` для каждого турнира. Только стандартная библиотека Python.
- `template.html` — внешний вид даша, данные подставляются вместо `/*DATA*/null`. Цвет «Записались» — `REG_ZONES`: до 20 синий, до 35 жёлтый, дальше красный.
- `cinzel.woff2` — шрифт заголовка (Cinzel Bold).

### Что берётся из таблицы (лист Main)

- E1 — квалификация, «(N slots)» превращается в «N слота».
- E2… до строки «Регистрация» — адрес (первая строка), «Участие …», банки («… по номеру телефона»), телефон, получатель (строка после телефона), ссылка t.me, «Наличными …».
- F:G — участники по алфавиту и галка оплаты.

### Новый турнир

1. Таблица: Файл > Поделиться > Опубликовать в интернете > лист Main > CSV.
2. Репо: Settings > Secrets and variables > Actions > New repository secret, ссылка с `output=csv`.
3. Строка в `config.json` с новым `id` и `"csv": "$ИМЯ_СЕКРЕТА"`.

Workflow `.github/workflows/main.yml` пересобирает сайт каждые 30 минут, при пуше и вручную. Все секреты репо попадают в сборщик сами, workflow править не нужно.
